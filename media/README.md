# Local demo music

Music is not uploaded to this repository. Place your own local copies here:

- `three_little_birds.flac` — default track (the supplied file is about 180 s).
- `here_comes_the_sun.flac` — alternative (the supplied file is about 186 s).

Or pass `--media /absolute/path/to/audio` to the launcher. The installer copies the user's two supplied FLAC files locally, without changing them. Git ignores audio files.
